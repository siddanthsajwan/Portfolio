# ✦ Siddanth Sajwan | Portfolio & Multi-Agent AI Systems

A modern, high-performance developer portfolio and autonomous AI agent showcase built with **React**, **Vite**, **Tailwind CSS**, **CrewAI**, and **Groq (Llama 3.1 8B)**.

---

## ⚡ Tech Stack & Architecture

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, Canvas Confetti
- **Agentic AI Simulation**: CrewAI Flows, Groq Cloud (Llama 3.1 8B Inference), Multi-Agent Tool Coordination (`GetThreadTool`, `CreateDraftTool`, IMAP SSL / SMTP)
- **Design System**: Cosmic Purple Gradient Dark Mode, Bento Grid Architecture, Glassmorphism, Responsive Typography

---

## 🚀 Key Features

1. **Autonomous Multi-Agent Email Pipeline Playground**:
   - Live interactive simulation of a 5-step CrewAI workflow (Health Check -> Email Classification -> Thread Context Retrieval -> AI Response Generation -> SMTP Draft Sync).
   - Real-time terminal log viewer & synthesized draft preview.

2. **Featured Systems & Deep-Dive Modals**:
   - *Autonomous Multi-Agent Email Auto-Responder*
   - *Autonomous Web & Research Analyst Agent*
   - *Social Media Automation Agent*
   - *AI Multi-Modal Learning Platform*
   - *ProElevate User Onboarding & Analytics Dashboard*

3. **Interactive Command Palette (`⌘K` / `Ctrl+K`)**:
   - Fast section jumping, one-click email copy, confetti triggers, and quick action shortcuts.

4. **Printable / PDF-Ready Resume Modal**:
   - Clean, standardized resume view formatted for single-click printing or PDF export.

## 🛠️ Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/siddanthsajwan/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```
